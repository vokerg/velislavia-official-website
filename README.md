# Официальный сайт Королевства Велиславия

Яркий адаптивный статический портал вымышленного государства, созданный как энциклопедия, государственная витрина и медиатека.

## Разделы

- общая информация и география;
- монархия, Королевский сейм и права граждан;
- подробная историческая хронология;
- экономика и валюта;
- Велеград, Моринск и Светобор;
- культура, сельская жизнь, праздник и спорт;
- художественные дипломатические визуализации;
- встроенный гимн «Балтийский гром»;
- полная галерея карт и изображений.

## Запуск локально

Сайт не требует сборки:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## GitHub Pages

В настройках репозитория выберите **Settings → Pages → Deploy from a branch** и укажите ветку `main`, каталог `/ (root)` после слияния pull request.

Велиславия — художественный проект вымышленного государства. Изображения встреч с реальными политиками являются явно обозначенными художественными визуализациями и не описывают реальные события.
